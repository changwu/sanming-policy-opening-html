时间：2014-03-21 17:14
为进一步加强师资队伍建设，促进我校各项事业发展，根据《三明市事业单位公开招聘工作人员暂行办法》
(
明人发
(2012)33
号
)
、《中共三明市委组织部、三明市公务员局关于确定三明市
2014
年人才引进和招聘紧缺急需专业的意见》
(
明人发
(2013]311
号
)
、《三明市公务员局关于核准
2014
年市属事业单位公开招聘工作人员计划的通知》
(
明人发
(2014]53
号
)
等文件精神，
2014
年三明市第二高级技工学校（筹）拟面向社会公开招聘紧缺专业教师
1
名。
本次招聘坚持“德才兼备、择优聘用”和“公开、平等、竞争、择优”的原则，按照向社会发布公告、公开报名及组织面试、体检、考核、公示、办理聘用手续等基本程序进行。现将有关招聘事项通告如下：
一、招聘基本条件和要求
1
．具有中华人民共和国国籍；
2
．遵守中华人民共和国宪法、法律、法规；
3
．遵守纪律、品行端正，具有良好的职业道德；
4
．
具备正常履行职责的身体条件
；
5
．
年龄18周岁以上， 30周岁以下(即在
1983年3月24日
至
1996年3月24日
期间出生)
；
6
．
具备符合招聘岗位要求的文化程度和工作能力。
报考者的毕业证书、学位证书及相关证书必须在
2014年9月30日前
取得）。
二、招聘岗位、专业及对象
招聘岗位：专技人员
(
教师
)
；
招聘专业：、汽车制造与装配技术
、汽车检测与维修技术
、汽车运用与维修、
汽车服务与维修、汽车维修工程教育。详见（
2014
年三明市
第二高级技工学校（筹）
公开招聘紧缺专业教师岗位信息表）。
招聘对象：
全日制普通教育本科及以上学历、学士及以上学位的应届毕业生。
